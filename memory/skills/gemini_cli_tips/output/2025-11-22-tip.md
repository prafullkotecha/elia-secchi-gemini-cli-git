# Gemini CLI Daily Tip - 2025-11-22

## Today's Tip: Effortless Context with the `@` Symbol

### Overview
One of the most powerful features of the Gemini CLI is the ability to instantly feed file or directory content into your prompt without manually copying and pasting. The `@` symbol acts as a direct bridge between your filesystem and the model.

### The Feature
By prefixing a file path or directory with `@`, you instruct the CLI to read that content and inject it directly into your prompt context. This is essential for code reviews, debugging, or summarizing documents.

**Example Usage:**
```bash
> @src/utils/helper.js Explain what this code does
```

**Multiple Files:**
You can chain multiple contexts to compare or combine files:
```bash
> @config/dev.json @config/prod.json Highlight the differences between these two configurations
```

### Why This Matters
*   **Speed:** Eliminates the tedious "open file -> select all -> copy -> switch window -> paste" workflow.
*   **Accuracy:** Ensures the model sees the exact, current state of the file.
*   **Flow:** Keeps you in the terminal and in your train of thought.

### How to Use It
1.  Start your prompt in the Gemini CLI interactive mode.
2.  Type `@` followed by the path to a file or folder.
3.  (Optional) If your terminal supports it, tab-completion often works to find the file quickly.
4.  Add your instruction after the path (e.g., "Fix the bug in this function").
5.  Press Enter. The CLI reads the file(s) and sends them along with your prompt.

### Pro Tips
*   **Directories:** using `@folder/` will often read *all* text-readable files in that directory (respecting `.gitignore` in many implementations). Use with caution on large directories to avoid token limits!
*   **Specifics:** Be specific with your instructions. Instead of just `@file`, try `@file Refactor this function to be more readable`.

### Related Features
*   `/clear`: Use this before starting a new context-heavy task to ensure a fresh slate.
*   `ReadFolder` / `ReadFile`: The underlying tools that `@` leverages.

### Quick Takeaway
Type `@filename` in your prompt to instantly let Gemini "see" your code or documents.
